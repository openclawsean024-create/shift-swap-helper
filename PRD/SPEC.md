# 排班換班助手 — PRD v3.0.2 等級規格書

> 建立日期:2026-09-19 · 對齊 SPEC v3.0 契約

## §1 產品概述

### 1.1 問題陳述
服務業（餐飲 / 零售 / 醫護）排班痛點：(1) 員工私下換班沒記錄，主管事後才知道 (2) 臨時請假要打電話一個一個問 (3) 工時計算常出錯，勞檢風險。本案提供「班表建檔 + 換班申請 + 主管審核 + 工時計算」。

### 1.2 目標使用者
- **Primary — 服務業員工**：餐廳服務生 / 門市店員 / 護理師
- **Primary — 主管/店長**：管理 5-50 人排班
- **Secondary — 人資**：工時報表 / 加班費計算

### 1.3 核心價值主張
> 換班 LINE 訊息改用系統：可追溯、可審核、可算工時。

### 1.4 Non-Goals
- ❌ 出勤打卡（用既有 POS / 人臉系統）
- ❌ 薪資計算（會計系統處理）
- ❌ 招募 / 履歷

---

## §3 FR

- FR-001: 班表建檔（週/月視圖、員工/時段模板）
- FR-002: 換班申請（雙方確認、原因、備註）
- FR-003: 主管審核（單鍵 approve/reject + 通知）
- FR-004: 工時計算（自動加總 / 加班偵測）
- FR-005: 通知（推播 + LINE + Email）
- FR-006: 報表（出勤時數 / 加班 / 請假統計）

## §4 NFR

- 通知 < 30 秒
- 工時計算 < 1 秒
- 勞基法合規檢查

## §5 技術棧

- IndexedDB（離線）
- Push notification
